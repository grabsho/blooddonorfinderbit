About This Project

🎯 Project Objective

Build a simple, responsive website to connect blood donors with those in need. Users can search donors by blood group and city, register as donors, and submit emergency requests — all without complex backend infrastructure.

🛠️ Tech Stack

  • HTML5 — Structure
  • CSS3 — Styling & Responsive Design
  • Vanilla JavaScript — Search, Filter, Form Validation
  • Google Apps Script + Google Sheets — Backend (Data Storage)

📚 Learning Outcomes

  • Multi-page website structure
  • Form handling & validation
  • DOM manipulation & dynamic content
  • Fetch API & serverless backend integration
  • Responsive design with media queries
  • Team collaboration & version control
