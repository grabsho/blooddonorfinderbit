About the Project

Connecting people through the power of blood donation.

Blood Donor Finder is a college mini project designed to make it easier to discover potential blood donors by blood group and location, register as a donor, and submit an urgent blood request.

What We're Building

A simple, accessible platform that demonstrates how web technology can support communication between people seeking blood donors and potential donors.

🎯

Project Objective

Develop a responsive website where users can search for potential donors, register their donor details, and submit blood requests. The goal is to provide a clear and easy-to-use interface backed by a lightweight serverless data system.

⚙️

How It Works

Users can browse the donor search page, provide registration details, or submit a blood request. The website uses JavaScript for interface interactions and Google Apps Script with Google Sheets for backend processing and data storage.

Technology Stack

The project combines standard web technologies with Google's serverless tools.

  • 🌐
    HTML5

    Provides the structure and content of each page.

  • 🎨
    CSS3

    Handles visual styling, layouts, and responsive design.

  • 💻
    Vanilla JavaScript

    Supports form interactions, validation, search, filtering, and dynamic page content.

  • ☁️
    Google Apps Script

    Provides the server-side functions that connect the website to its data source.

  • 📊
    Google Sheets

    Acts as the project's data store for supported application records.

Important Safety Note

Blood Donor Finder is a college project and is not a substitute for professional medical care or an emergency response service. Donor listings and submitted requests must be verified independently. In an emergency, contact local emergency services or the nearest hospital rather than waiting for a response from this website.
